CONCEPT

Laboratorium ini menghubungkan dua sudut pandang yang sering dipelajari terpisah: organisasi perangkat keras dan alur eksekusi instruksi. Pertama, pengguna membongkar package processor secara visual. Setelah itu, silicon die dibaca sebagai kumpulan resource pemrosesan seperti core, cache, ALU, Control Unit, dan register.

Tujuannya bukan sekadar mengenali nama komponen. Pengguna diharapkan memahami bahwa sebuah instruksi membutuhkan perpindahan informasi melalui beberapa bagian CPU sebelum menghasilkan keadaan register yang baru.

Inti konsep: hardware menjelaskan di mana pekerjaan berlangsung, sedangkan instruction flow menjelaskan bagaimana informasi bergerak.
Cara Menggunakan Lab
Urutan yang disarankan
  1. Klik BONGKAR CPU dan amati perubahan jarak antar layer.
  2. Klik Silicon Die untuk memusatkan kamera pada bagian semikonduktor.
  3. Inspect Core, Cache, ALU, Control Unit, dan Register satu per satu.
  4. Jalankan INSTRUKSI MANUAL agar setiap tahap bisa diamati.
  5. Gunakan INSTRUKSI OTOMATIS untuk melihat seluruh alur sebagai satu rangkaian.
Tip: lakukan mode manual terlebih dahulu. Saat pengguna sudah memahami fungsi tiap blok, mode otomatis akan terasa seperti rangkaian sebab-akibat, bukan sekadar animasi.

OVERVIEW

Processor dapat dipahami sebagai sistem yang menerima instruksi, mengatur data, dan mengubah keadaan internalnya. Pada lab ini, pembahasan sengaja dipusatkan pada processor dan RAM agar hubungan antara memori utama dan unit pemrosesan dapat diamati tanpa distraksi hardware lain.

Ketika CPU dibongkar, layer fisik digunakan sebagai jembatan menuju konsep arsitektur komputer. Silicon die menjadi titik masuk untuk melihat resource pemrosesan yang bekerja di balik package.

RAM → CACHE → REGISTER
DECODE → CONTROL → OUTPUT
Perhatikan: hubungan spatial antar objek adalah bagian dari materi. Letak RAM di samping CPU sengaja digunakan untuk membantu pengguna menghubungkan memori dengan jalur data.
